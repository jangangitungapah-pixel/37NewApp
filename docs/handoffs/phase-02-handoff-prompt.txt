CAKUPAN PHASE 02 (BUSINESS MASTER DATA):
1. **Business Profile & Settings (`profile/main`, `settings/{business,schedule,pricing,commission,bookingPolicy}`)**:
   - Jam operasional default `10:00–22:00`, timezone `Asia/Jakarta`, `currency: 'IDR'`, `slotGranularityMinutes` default `15`.
   - Owner-only write; Operator read ter-scope data operasional yang dibutuhkan.
2. **Studios / Rooms (`businesses/{businessId}/studios/{studioId}`)**:
   - CRUD lengkap untuk Owner (name, code, status active/inactive, timezone, operatingHours, slotGranularityMinutes).
   - Operator hanya boleh membaca studio dalam `assignedStudioIds` miliknya.
3. **Services, Pricing & Commission Policies (`businesses/{businessId}/services/{serviceId}` & settings)**:
   - Layanan awal: `Rehearsal`, `Recording`, `Mixing`, `Mastering`, dengan `durationOptions`, `pricingModel` (durasi/paket/nilai khusus), `active`, versi config (`configVersion`), dan nilai uang integer rupiah (tanpa floating-point).
   - Aturan komisi (persentase / nominal tetap / kebijakan per service atau operator) dikelola oleh Owner.
4. **Customers (`businesses/{businessId}/customers/{customerId}`)**:
   - Database customer ter-scope bisnis; Owner full CRUD; Operator akses operasional sesuai permission (tanpa menghapus data historis).
5. **Team Membership & Assignment (`businesses/{businessId}/members/{uid}`)**:
   - Owner dapat mengundang/mendaftarkan member Operator/Owner (catatan Spark-only: tanpa Cloud Functions Admin SDK, penyiapan akun Auth baru/penautan UID oleh Owner harus didokumentasikan secara jelas dan jujur), mengatur `role`, `status`, `assignedStudioIds`, dan `permissions`.
6. **Firestore Rules & Indexes**:
   - Buka aturan tervalidasi (allowlist, tipe data, integer money check, role/studio scope check) di `firestore.rules` HANYA untuk koleksi Phase 02; biarkan Phase 03+ (`bookings`, `bookingSlots`, `ledgerEntries`, `commissionEntries`, `galleryAssets`) tetap deny-by-default.
   - Tambahkan composite index / `fieldOverrides` di `firestore.indexes.json` untuk setiap query baru (terutama query multi-field, filter + orderBy, dan collection group).
